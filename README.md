# Hall-Meal-Management-System-C
•	Designed and developed a console-based Hall Meal Management System with student registration, login, meal booking, updating,   cancellation, and meal tracking features.
•	Implemented an admin management panel for viewing students, monitoring meal orders, calculating kitchen meal counts,           managing delivery status, and generating delivery reports.
•	Added file-based data persistence to securely store and load student and meal records between program executions.
•	Applied structures, arrays, functions, input validation, and file handling to build a modular and reliable C application.
•	Independently developed the project end-to-end as a solo developer.
•	Technologies used: C, Structures, Arrays, Functions, File Handling, Standard C Library
